The Freewebs Era - Site History

The oldest public iteration of my website began on a free web host known at the time as Freewebs. Freewebs was similar to today's Neocities or Nekoweb, in that it let you host static HTML files and edit that HTML directly in a web-based editor. Freewebs also had a WYSIWYG editor for beginners. Websites were hosted on the Freewebs domain, but there were paid hosting plans as well.

After playing around with local HTML files on my computer, I was very excited to start developing a website that other people could visit for themselves. I wanted to write a bunch of articles and have exciting content for people visiting the site.

I've had a Random Stuff section since the beginning...

On modern browsers, the main content layout is completely broken, though I swear it worked when I originally wrote it. On Internet Explorer at least.

The main article shouldn't be overlapping the "Site Navigation" section. But what did I know back in 2008.

On the archived version of this website, I've removed some of the old traces of some mandatory Freewebs advertising code on each page, and also fixed some broken links. I had a "free" domain name ad on my site as well, but the site has long died so I've replaced the ad with a placeholder. Most of the Random Stuff content is broken, so I haven't included those pages in the archive. At least you can read my old "articles".

The "Remote" is another completely broken feature. All it did was pop up a window that acted as a "remote control" for the main window. You did not need it at all.

The previously archived Developer's Blog section of the site is included in the archive and can be accessed by double clicking the hyphen character near the bottom of the "Announcements" page.

While I was working on this site, I was also learning PHP and MySQL and messing around with those locally on my own computer. I really wanted to build something even more complex, and so I grew a bit tired of Freewebs and wanted to move onto something more powerful and interesting.

Motif/2.0 - Site History

Welcome to the current iteration of this site! Heavily based on the Windows 95 theme from the site's launch, I've given the main design a new coat of paint inspired by early UNIX desktop environments running on the X Window System.

I've kept the navigation/content window layout pretty much exactly the same, so the overall look and feel of the website's not changed too much besides the framing aesthetics. The navigation window's icons have mostly been replaced, sourced from a wider diversity of older OS icons. Most content pages have remained exactly the same, though I have touched up a few pages for this redesign.

The windows teal has been replaced with a stylized version of The X Window System's Root Weave, as well as the sunrise/sunset and night mode backgrounds. I think this overall gives everything a cozier retro feel (well, dated X graphics look cozy to me anyway) and makes the color palette of the site slightly more cohesive.

One of the bigger additions that's hard to miss is the addition of various UNIX desktop toys in the previously empty bottom left corner of the screen. When I came up with the idea of old UNIX graphical theming, I knew I wanted to add something like xeyes to the site to fill up that empty corner.

I settled on three specific decorations that could be randomly selected for each page: xclock, xeyes, and a terminal window that represents both cowsay and fortune. Porting all of these utilities over to JavaScript was a fun side project though it was definitely one of the more time-consuming parts of this whole redesign. Some of the C code I was using as reference was decades old and wasn't exactly in the best condition.

And yes, I ported over xeyes and xclock to JavaScript by myself! I strove to make these pretty accurate ports, so as an easter egg I've also supported the biblicallyAccurate mode of xeyes as well. I've also added a few additional features to both, like adding keyboard accessibility to xeyes and adding some easter eggs to both programs. I did end up using a pre-existing port of cowsay instead though.

At some point during the process, I liked the idea of having these "little guys" on my site, having funny little comments to add to each page. So while they have a random pool of general things they'll say, there are unique things they'll also say on every specific page of this site!

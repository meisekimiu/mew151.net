Mew151.net 1.0 - Site History

After languishing away as an empty landing page for over a decade, in February 2022 Mew151.net finally launched! It only took over a decade to finally happen!

The initial design for Mew151.net was inspired by Windows 95, as I started getting into retro computing a few years before. I liked the idea of having the site navigation be its own floating window similar to a Windows file explorer, while the main site content was its own bigger window. I also liked the idea of the main content section having pretty plain "Web 1.0" layouts since the framing of the rest of the page was already quite unique.

The styling for these windows actually started a few years prior on a completely different and unreleased project. In 2020 I started working on a game that I titled Job Search Deluxe, which would have been about a closeted transgender woman trying to navigate the job search while also still navigating the whole gender thing. I wanted to develop an accurate fake operating system that the game would take place within, and this is where I first developed the faux-Windows 95 styled windows that would eventually debut on Mew151.net.

While many "fake OS"-styled websites allow you to drag the windows around, I actively chose to avoid that on this site since I didn't want that to distract from the main page content. It might also seem curious that while the windows were themed like Windows 95, I omitted the familiar Windows taskbar, Start menu, and desktop icons. Well, since I actually use a pretty non-standard Linux desktop environment, I don't actually have a taskbar or desktop icons. So I never included those elements to match my own preferences on my actual computer.

Where's the Start menu?

One thing I was pretty happy with implementing on this site was a background the reacts to the current time. During the day, you'd get standard Windows teal, but during the night you'd get a starry background. In between night and day, you'd get a sunrise/sunset background for an hour. And after midnight for a few hours you'd get some flying toasters. Backgrounds changing depending on the time of day was an idea I had many years ago, so it's nice to have it finally implemented on my site for real.

Around 2025, I started wanting to adjust the design of the site. As mentioned, I don't actually use Windows anymore, so having a site themed around Windows 95 felt odd for me. I also felt like there was an awkward empty area in the bottom left corner of the screen. I wondered if I could put anything there. Ideas started flowing and I began writing down tickets for "Mew151.net 2.0".

Some site improvements that came between then and the next chapter were included in this "2.0" work. The Kid Pilot article was actually grouped together in this 2.0 work, but since it was just content it launched much earlier.
